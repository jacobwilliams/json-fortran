A simple hash table implementation for a JSON structure.

This module defines a hash table type with methods for initialization, insertion, lookup, and deletion. It uses the DJB hash algorithm for hashing string keys and supports optional case-insensitive key comparison.

It can be used independently, or in a json_file object to speed up lookups of the root-level members of the JSON file.

private subroutine hash_table_create_from_value(me, json, p, status_ok, initial_capacity)

Create a hash table from the children of an existing JSON object. The keys are the object member names and the values are pointers to the associated JSON values.

Arguments

class(json_hash_table), intent(out) :: me
type(json_core), intent(in) :: json

the JSON core factory to use for this hash table. a copy of this will be made and stored in the table.
type(json_value), pointer :: p

the JSON value whose children will be used to populate the hash table. This must be a JSON object.
logical(kind=LK), intent(out) :: status_ok

true if no problems.
integer(kind=IK), intent(in), optional :: initial_capacity

initial capacity of the hash table (number of buckets). If not provided, it will be set based on the number of members divided by the load factor to minimize the number of resizes needed as members are inserted
